# 🍗 Recipe Card Page

A simple and responsive **Recipe Card Page** built using HTML5 and CSS3.  
This project displays a delicious Chicken Biryani recipe with an image, ingredients list, and step-by-step preparation instructions.

## 📌 Project Overview

The Recipe Card Page is designed to practice:

- Semantic HTML structure
- HTML lists
- Images and figures
- CSS card styling
- Responsive web design
- Clean and organized UI

## ✨ Features

- 🍗 Chicken Biryani recipe
- 🖼️ Recipe image with caption
- 🥘 Ingredients list
- 📝 Numbered preparation steps
- 📱 Mobile responsive design
- 💻 Desktop-friendly layout
- 🎨 Modern card-based UI
- 🌈 Attractive background and styling

## 🛠️ Technologies Used

- HTML5
- CSS3
